# Reproduction map

One row per paper item. Commands run from the repository root with `uv run` (prefix
omitted below; `+gen` = `uv run --extra generate`, `+stats` = `uv run --extra stats`,
`+esa` = `uv run --extra esa`).
Inputs are the released data (`data/processed`, `data/raw`, see the main README); outputs
go to `results/` (gitignored). Expected values and tolerances are detailed in each
experiment README and in [`.claude/skills/qgf-paper/references/claims.md`](../.claude/skills/qgf-paper/references/claims.md).

Status: **done** = ported and validated; **running** = ported,
full reproduction still in progress; **coming** = not in the repository yet, to be
contributed; **to be decided** = inclusion not decided yet.

"Expected" gives the value produced by this repository (reference tables under
`experiments/*/expected/`).

**Walkthrough:** [`reproduce/walkthrough.ipynb`](walkthrough.ipynb) goes through the paper in
order (then the experiments added here): what each item shows, what to run, the caveats, and
where the results are.

**Exact reproduction.** ESA (Table 4), the downstream GNNs (Tables 2-3, geometry and hardware
tables), the ablations (Tables 8-10) and the non-unit-disk benchmark reproduce the published
trials bit for bit with the pinned environment of the original runs,
[`reproduce/paper_env`](paper_env/pyproject.toml) (`uv sync --frozen --project
reproduce/paper_env`; Python 3.11, torch 2.4.0 + CUDA 12.1, PyG 2.6.0, xformers 0.0.27.post2,
Lightning 2.5.3), the repository sources on `PYTHONPATH=src`, and the hardware / thread count
of the original runs (ESA: A100, xformers attention; GNNs and ablations: AMD EPYC 7742 CPU
nodes, 1 or 4 threads per process as documented per experiment). The Slurm wrappers select it
with `ESA_ENV=paper`, `GNN_ENV=paper`, `ABL_ENV=paper`. The project environment gives
statistically equivalent but not bit-identical trials.
